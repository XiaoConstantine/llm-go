# llm-go

`llm-go` is a provider-neutral Go library for text generation, streaming,
tool use, and multimodal content.

The project favors small explicit interfaces, typed provider configuration,
and standard Go lifecycle conventions. It does not depend on an agent or
prompt-programming framework.

The implementation is under active development and has not published a stable
API yet.

Requires Go 1.27 or newer.
